📚 API Endpoints

GET /problem/:contestId/:index
Get a specific problem by contest ID and index
curl https://your-space.hf.space/problem/1/A
GET /index
Get list of all scraped problem IDs
curl https://your-space.hf.space/index
GET /image/:filename
Get a cached problem image
curl https://your-space.hf.space/image/1-A_diagram.png
GET /
Health check and API status
curl https://your-space.hf.space/

ℹ️ About

This API provides access to scraped Codeforces problems with intelligent parsing. The scraper uses a persistent browser profile with randomized timing to bypass Cloudflare protection. All problems are stored in MongoDB and served through this API.

Note: This is a read-only deployment. Scraping is done locally and problems are synced to the shared MongoDB database.

Built with ❤️ using Python, Flask, and MongoDB
