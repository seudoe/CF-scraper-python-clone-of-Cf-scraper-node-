F. Polygonal Segments
time limit per test
8 seconds
memory limit per test
512 megabytes
input
standard input
output
standard output

You are given an array aa of size nn.

A segment [l,r](1≤l<r≤n)[l,r](1≤l<r≤n) is called a polygonal segment only if the following conditions hold:

  • (r−l+1)≥3(r−l+1)≥3;
  • Considering al,al+1,…,aral,al+1,…,ar as side lengths, these sides can form a polygon with (r−l+1)(r−l+1) sides.

Process qq queries of two types:

  • "1 l r": find the length of the longest segment among all polygonal segments [l0,r0][l0,r0] satisfying l≤l0≤r0≤rl≤l0≤r0≤r. If there is no such polygonal segment, output −1−1 instead;
  • "2 i x": assign ai:=xai:=x.
Input

The first line contains an integer tt (1≤t≤1041≤t≤104) — the number of test cases.

For each test case:

  • The first line of each testcase contains two integers nn, qq (4≤n≤2⋅1054≤n≤2⋅105, 1≤q≤1051≤q≤105);
  • The second line of each testcase contains nn integers a1,a2,…,ana1,a2,…,an (1≤ai≤10121≤ai≤1012);
  • The following qq lines contain the description of queries. Each line is of one of two types:
    • "1 l r" (1≤l<r≤n1≤l<r≤n, r−l+1≥3r−l+1≥3);
    • "2 i x" (1≤i≤n1≤i≤n, 1≤x≤10121≤x≤1012).

It is guaranteed that the sum of nn over all test cases will not exceed 2⋅1052⋅105, and the sum of qq over all test cases will not exceed 105105.

Output

For each query, if there is no suitable segment, output −1−1 in a new line. Otherwise, output the length of the longest segment satisfying the condition above in a new line.

Note

In the first query of the first test case, there is no polygonal segment under the given condition. For example, considering segment [1,3][1,3], you can not form a triangle with side lengths of a1=3a1=3, a2=1a2=1, and a3=2a3=2.

In the second query of the first test case, the longest polygonal segment is [1,4][1,4]. You can form a quadrilateral with side lengths of a1=3a1=3, a2=1a2=1, a3=2a3=2, and a4=2a4=2.
